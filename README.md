
# Proxmox Automation Suite

Набор скриптов и конфигураций для автоматизации задач на Proxmox VE и
внутри контейнеров/виртуальных машин. Проект разделён на два основных
направления:

* **Create-Contaner** – интерактивный генератор LXC‑контейнеров на Proxmox
* **Install-Roles** – набор ролей для настройки окружения (веб‑стек, LDAP,
  Samba AD, базовая конфигурация и др.)

Каждая часть имеет собственный README с подробной документацией, но
ниже приведено краткое описание проекта в целом.

## Create-Contaner (LXC Auto-Creator)

Интерактивный Bash‑скрипт (`Create-Contaner/main.sh`) позволяет в несколько
шагов создать контейнер LXC на узле Proxmox. Скрипт:

* загружает настройки из `config.conf` (копировать из `config.conf.example`)
* показывает список доступных шаблонов, позволяет выбрать один
* запрашивает параметры (имя, vCPU, RAM, диск, сеть, VLAN, DHCP/статический IP)
* генерирует либо просит указать пароль root
* опционально устанавливает пакеты для VNC
* опционально запускает внешний скрипт внутри контейнера (URL задаётся в
  конфиге)
* отправляет уведомление в Telegram (если настроено)
* автоматически подбирает свободный CTID

Всё описано подробнее в `Create-Contaner/README.md` – там же есть примеры
использования, объяснение конфига и отладка.

## Установочные роли (`Install-Roles`)

Этот каталог содержит несколько скриптов, которые можно использовать как
после создания контейнера/машины, так и отдельно по своему усмотрению.

### Веб‑стек (`web-stack`)

Полностью изолированный `docker-compose`‑проект для развертывания nginx+
php‑fpm+mysql с автоматическим управлением сайтов и сертификатов Let’s
Encrypt. Главные артефакты:

* `docker-compose.yml` – описание сервисов
* `install-web-server` – утилита для добавления нового сайта (создание
  структуры, конфигов, БД, запрос сертификата)
* `app/nginx/nginx.conf` – общие настройки nginx, включая обработку ACME
  challenge
* `README.md` – подробное русское руководство (см. внутри `web-stack`)

### Другие скрипты

* `basic-setting-machine.sh` – базовая «чистовая» настройка Debian/Ubuntu
  (пакеты, локаль, ssh, пользователь, интерфейсы)
* `basic-setting-contaner.sh` – похожий скрипт, оптимизированный для
  LXC‑контейнера (логирует в `/var/log/post_install.log`)
* `install_samba_ad.sh` – установка и настройка контроллера домена Samba4
* `ldap_ssh.sh` – конфигурирование SSH и LDAP‑клиента в Debian-подобных
* в дальнейшем сюда могут добавляться дополнительные ролики/профили

Запуск любого из этих скриптов обычно осуществляется внутри Развернутой
системы: скопируйте соответствующий файл и выполните его от root.

## Общие рекомендации

1. Всегда проверяйте права и запускайте скрипты от root (sudo).
2. Резервируйте конфигурационные файлы перед изменением.
3. Для автоматизации внутри контейнера используйте `EXTERNAL_SCRIPT_URL`
   в конфиге Create-Contaner.
4. Регулярно обновляйте Docker‑стек и образы (`docker-compose pull`).
5. Изучайте README в каждой подсекции – они содержат подробные примеры и
   ответы на часто возникающие вопросы.
